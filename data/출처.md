# 서울시 주요 공원현황 데이터 출처 및 수집 정보

## 1. 데이터 기본 정보

- 데이터명: 서울시 주요 공원현황
- 제공 기관: 서울특별시
- 데이터 제공 사이트: 서울열린데이터광장
- 원본 파일명: 서울시 주요 공원현황(2026 하반기).xlsx
- 데이터 갱신일: 2026년 9월 23일

## 2. 데이터 출처

- 공식 데이터 페이지: https://data.seoul.go.kr/dataList/OA-394/S/1/datasetView.do?tab=A
- 데이터 이용 조건: 공공누리 제1유형(출처표시)

## 3. 데이터 구성

- 원본 데이터 열 수: 20개
- 전처리 후 분석에 사용한 공원 수: 116개
- 주요 분석 항목:
  - 공원명
  - 공원 면적
  - 주요 시설
  - 지역

## 4. 데이터 수집 및 활용 목적

서울시 공원들의 면적과 주요 시설 정보를 분석하여 공원마다 어떤 특징이 있는지 알아보기 위해 해당 데이터를 수집하였다. 수집한 데이터는 결측치와 이상치를 확인하고 필요한 항목을 전처리한 뒤, K-means 군집 분석에 활용하였다.

## 5. 개인정보 및 이용 조건

본 프로젝트에서는 공원에 관한 공공데이터만 사용하였으며, 개인을 식별할 수 있는 정보는 분석에 사용하지 않았다. 데이터 이용 시 공공누리 제1유형의 출처표시 조건을 따른다.
