# 4차시 기록: 데이터 살펴보기

## 20816 이상현

- 오늘 결정한 것: 서울시 주요 공원현황 데이터에서 공원명, 공원 면적, 주요 시설, 지역을 중심으로 살펴보기로 했다. 전체 데이터 중 분석에 사용할 공원이 116개라는 것을 확인했다.
- AI에게 보낸 프롬프트(원문): 서울시 주요 공원현황 엑셀 파일을 분석하려고 해. 데이터에 어떤 열이 있는지 확인하고, 공원 면적의 최솟값, 최댓값, 평균과 빈 값이 몇 개인지 확인하는 방법을 알려줘.
- **AI가 준 것 중 고치거나 버린 것과 그 이유:** AI가 제안한 모든 열을 분석에 사용하는 방법은 제외했다. 탐구 주제와 직접적인 관련이 적은 열까지 사용하면 분석이 복잡해질 수 있기 때문에 공원명, 공원 면적, 주요 시설, 지역을 중심으로 분석하기로 했다.
- **느낀 점:** 공원 데이터에는 생각보다 다양한 정보가 들어 있었다. 면적과 시설을 함께 살펴보면 공원마다 어떤 차이가 있는지 알 수 있다는 것을 느꼈다.
- **AI 없이 내가 스스로 한 것:** 원본 엑셀 파일을 직접 열어 데이터의 전체적인 구성을 확인하고, 탐구에 필요한 열을 골랐다.

## 20822 장민지

- **오늘 결정한 것:** 공원 면적뿐만 아니라 주요 시설의 종류도 공원을 구분하는 중요한 기준이라고 판단했다. 따라서 면적과 시설 정보를 함께 활용해 비슷한 특징을 가진 공원끼리 유형을 나누기로 했다.
- **AI에게 보낸 프롬프트(원문):** 서울시 주요 공원현황 데이터를 활용해서 공원들을 면적과 주요 시설의 특징에 따라 유형별로 나누고 싶어. 분석에 필요한 데이터 전처리 방법과 공원 유형을 구분하는 방법을 알려줘.
- **AI가 준 것 중 고치거나 버린 것과 그 이유:** AI가 제안한 유형 구분 방법을 그대로 사용하지 않고, 실제 데이터에 포함된 공원 면적과 시설 정보를 기준으로 분석하기로 했다. 데이터에 없는 시설 정보를 임의로 추가하면 분석 결과가 정확하지 않을 수 있기 때문이다.
- **느낀 점:** 공원은 모두 비슷한 공간이라고 생각했지만, 면적과 시설에 따라 서로 다른 특징을 가진다는 것을 알게 되었다. 데이터를 활용하면 공원들의 차이를 객관적으로 비교할 수 있을 것 같다.
- **AI 없이 내가 스스로 한 것:** 서울열린데이터광장에서 원본 데이터의 출처와 이용 조건을 확인하고, 실제 엑셀 파일을 살펴보며 탐구에 필요한 정보를 정리했다.
