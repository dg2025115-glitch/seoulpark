# 3차시 기록: 데이터 판정·선생님 승인

## 20816 이상현

- **오늘 결정한 것:** 서울시 주요 공원현황 데이터를 분석 자료로 선정했다. 공원별 면적과 주요 시설 정보가 있어 공원의 특징에 따라 유형을 나누는 데 적합하다고 판단했다.
- **AI에게 보낸 프롬프트(원문):** 서울시 주요 공원현황 데이터로 공원마다 면적과 주요 시설의 특징에 따라 어떤 유형으로 나뉘는지 분석하려고 해. 이 데이터가 분석 질문에 충분한지, 적합한지, 법적·윤리적으로 문제가 없는지 판단해 줘.
- **AI가 준 것 중 고치거나 버린 것과 그 이유:** AI가 데이터의 모든 항목이 분석에 필요하다는 식으로 설명한 부분은 그대로 사용하지 않았다. 실제 분석에 필요한 면적과 주요 시설을 중심으로 판단하고, 나머지 항목은 분석 목적에 따라 활용 여부를 결정했다.
- **느낀 점:** 데이터를 많이 모으는 것보다 분석하려는 질문에 적합한 데이터를 선택하는 것이 중요하다는 것을 알았다.

## 20822 장민지

- **오늘 결정한 것:** 서울시 공공데이터를 활용하기로 하고, 데이터의 원래 출처와 제공 기관을 확인했다. 이후 GitHub에 팀 저장소를 만들고 프로젝트에 필요한 파일과 코드를 관리하기로 했다.
- **AI에게 보낸 프롬프트(원문):** 서울시 주요 공원현황 데이터를 활용해 데이터 분석 프로젝트를 진행하려고 해. 데이터 출처를 확인하고 GitHub에 프로젝트 저장소를 만드는 방법을 알려 줘.
- **AI가 준 것 중 고치거나 버린 것과 그 이유:** AI가 제안한 여러 분석 방향 중 공원 면적과 주요 시설을 활용한 군집화 분석을 선택했다. 공원마다 특징이 다르기 때문에 비슷한 공원끼리 묶어 비교하는 것이 적절하다고 생각했다.
- **느낀 점:** 분석을 시작하기 전에 데이터의 출처와 활용 목적을 명확히 정해야 프로젝트의 신뢰도를 높일 수 있다는 것을 알았다.
