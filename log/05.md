# 5차시 기록: 전처리(서울시 공원 데이터)

## 20816 이상현

- **오늘 결정한 것:** 공원 면적 데이터에 쉼표와 단위가 포함되어 있어 숫자로 변환했다. 면적이 없거나 단위를 확인하기 어려운 공원 등은 분석에서 제외했고, 최종적으로 116개 공원을 분석에 활용했다.
- **AI에게 보낸 프롬프트(원문):** 서울시 공원 데이터의 면적 항목에 쉼표와 단위가 포함되어 있어. 머신러닝 분석에 사용할 수 있도록 숫자로 변환하는 방법과 분석에 적합하지 않은 데이터를 처리하는 방법을 알려 줘.
- **AI가 준 것 중 고치거나 버린 것과 그 이유:** AI가 결측치를 평균으로 채우는 방법을 제안했지만, 면적을 알 수 없는 공원이 평균 면적을 가진다고 볼 근거가 없어서 사용하지 않았다.
- **느낀 점:** 데이터를 머신러닝에 사용하려면 단순히 불러오는 것뿐 아니라 분석에 적합한 형태로 바꾸는 과정이 중요하다는 것을 알았다.

## 20822 장민지

- **오늘 결정한 것:** 공원 면적의 이상치를 IQR 방법으로 확인했다. 이상치로 확인된 공원 19개를 무조건 삭제하지 않고, 실제로 면적이 큰 공원일 가능성을 고려해 분석 목적에 맞게 처리했다.
- **AI에게 보낸 프롬프트(원문):** 서울시 공원 면적 데이터에서 IQR 방법으로 이상치가 19개 발견됐어. 이상치를 전부 삭제하는 것이 적절한지, 실제 대형 공원과 데이터 오류를 어떻게 구분하면 좋을지 알려 줘.
- **AI가 준 것 중 고치거나 버린 것과 그 이유:** 이상치를 모두 삭제하자는 방식은 사용하지 않았다. 면적이 큰 공원은 실제로 존재할 수 있기 때문에 이상치라는 이유만으로 잘못된 데이터라고 판단할 수 없다고 생각했다.
- **느낀 점:** 이상치는 무조건 제거해야 하는 데이터가 아니라 실제 값인지 확인하고 분석 목적에 맞게 처리해야 한다는 것을 알았다.
