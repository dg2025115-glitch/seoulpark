# 오늘의 활동 기록

## 20816 이상현

1. 오늘 결정한 내용:** 서울시 공원 데이터를 활용하여 공원의 면적과 주요 시설에 따라 3개의 유형으로 군집화하기로 했다.
2. 사용한 AI 프롬프트:** 서울시 주요 공원현황 데이터를 활용하여 결측치와 이상치를 확인하고 K-means 군집 분석을 진행하는 Streamlit 코드를 작성해 줘.
3. 수정하거나 제외한 내용과 이유:** 면적이 비어 있거나 단위가 명확하지 않은 데이터는 분석의 정확성을 위해 제외했다.
4. 활동 소감:** 데이터를 직접 정리하고 분석하면서 전처리 과정이 분석 결과에 큰 영향을 준다는 것을 알게 되었다.

## 20822 장민지

1. 오늘 결정한 내용:** 공원의 면적과 주요 시설을 기준으로 공원들의 특징을 비교하기로 했다.
2. 사용한 AI 프롬프트:** K-means 군집 분석 결과를 표와 그래프로 시각화하고 각 군집의 특징을 설명해 줘.
3. 수정하거나 제외한 내용과 이유:** 면적 데이터 중 단위가 불분명하거나 값이 비정상적인 항목은 분석에서 제외했다.
4. 활동 소감:** 군집 분석과 그래프를 통해 공원마다 서로 다른 특징이 있다는 것을 확인할 수 있었다.
