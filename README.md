# 서울공원탐구: 서울시 공원은 어떤 특징에 따라 유형이 나뉠까?

## 1. 팀원
- 20816 이상현
- 20822 장민지

## 2. 탐구 질문
서울시 공원은 면적과 주요 시설의 특징에 따라 어떤 유형으로 나뉠까?

## 3. 주제 선정 이유
공원마다 면적과 시설이 다르기 때문에 데이터를 활용하면 공원들의 특징을 객관적으로 비교할 수 있다고 생각했다. 또한 비슷한 특징을 가진 공원들이 어떤 유형으로 묶이는지 확인하고, 서울시 공원들의 특징을 더 쉽게 이해하고 싶었다.
